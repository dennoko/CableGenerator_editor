# 実装設計

## 概要
実装の具体設計。クラス構成、メソッド要件、メッシュ生成のフロー、最適化方針を示す。

## クラス図（概念）

### Runtime
- `CableProfile : ScriptableObject`（抽象）
  - `abstract Vector2[] GetVertices()`
  - `abstract Vector2[] GetNormals()`
  - `abstract float[] GetUCoords()`
  - `virtual int GetVerticesPerLoop()` — 1ループあたりの頂点数（複合形状で使用）
  - `virtual float[] GetPerimeters()` — 各ループの周長（UV1パッキングで使用）
- `CableGenerator : MonoBehaviour`
  - 必須コンポーネント: `SplineContainer`, `MeshFilter`, `MeshRenderer`
  - プロパティ: `public CableProfile profile; public int resolution; public float uvTiling;`
  - 内部: `Mesh generatedMesh; List<Vector3> verts; List<int> tris; List<Vector3> normals; List<Vector2> uvs; List<Vector2> uv2s;`
  - UV1 パッキング: `StripInfo`, `UV1Layout` 構造体と棚パッキングアルゴリズム
- `CableKnotAttachment : MonoBehaviour`
  - スプラインのノットにオブジェクトをアタッチする機能
  - プロパティ: `knotIndex`, `positionOffset`, `rotationOffset`, `scale`

### Editor
- `CableGeneratorInspector : Editor`
  - Inspector UI（プロファイル設定、メッシュ再生成、メッシュ保存、アタッチメント）
  - Scene ビューハンドル（制御点、タンジェント、プレビュー線）
- `CableMeshExporter`（静的ユーティリティ）
  - `SaveMeshAsset()` — メッシュを `.asset` として保存
  - `EnsureFolderExists()` — フォルダの自動作成

## `CableProfile` 継承一覧
- `HeavyDutyCableProfile`：太丸断面（オプションでリブ凹凸）
- `FlatCableProfile`：角丸長方形
- `ParallelWireProfile`：2つ円のメガネ型
- `BundledCableProfile`：横一列の複数ワイヤー
- `ClusteredCableProfile`：同心円パッキングの複数ワイヤー

## 受け入れテスト（実装時に確認する）
- シーン上で始点・終点2クリックで生成されること
- 制御点移動でメッシュ形状が即時更新されること
- 複数プロファイル切替で見た目が変わること
- Undo/Redo が機能すること


## `CableGenerator` の振る舞い
1. `OnEnable()` で `Spline.Changed` イベントを購読、`OnDisable()` で解除
2. イベントまたは Inspector 値変更で `RebuildMesh()` をスケジューリング
3. `RebuildMesh()` のフロー:
   - Mesh 初期化 / キャッシュ取得（`generatedMesh = generatedMesh ?? new Mesh()`）
   - `generatedMesh.MarkDynamic(); generatedMesh.Clear(); verts.Clear(); tris.Clear(); normals.Clear(); uvs.Clear();`
   - スプライン長を計算し、累積距離ベースで V のスケールを決定
   - `t` を sampling 間隔で進め、`SplineUtility.Evaluate`（または同等）で `position, tangent, up` を取得
   - 各 sampling 毎に `profile.GetVertices()` を用いて 2D 頂点を 3D に変換して追加
   - 各セグメントの頂点インデックスを繋いで `tris` に追加
   - 法線は profile の 2D 法線を 3D に変換して `normals` に追加
   - `generatedMesh.SetVertices(verts)` 等でメッシュに反映、`generatedMesh.RecalculateBounds()` を呼ぶ

## 最適化ポイント
- Mesh の new を避ける（生成は一度のみ）
- `List<T>` をフィールドにして Clear/Reuse
- 変更影響範囲の差分再計算（大規模実装）
- エディタ更新の間引き（必要なら debounce）を検討

## エディタ UI 実装要点
- `CustomEditor(CableGenerator)` で Inspector を拡張
- `OnSceneGUI()` で `Handles` を使って制御点表示・移動
- `EditorGUI.BeginChangeCheck()` → `Undo.RecordObject()` → `EditorUtility.SetDirty()` を必ず行う
- Inspector の構成:
  1. プロパティフィールド（断面プロファイル、分割数、UVタイリング）
  2. 「メッシュを再生成」ボタン
  3. メッシュ保存セクション（保存先フォルダ設定 + 保存ボタン）
  4. アタッチメントセクション（各ノットへのアタッチメント追加ボタン）

## メッシュ保存（Bake）
- `CableMeshExporter.SaveMeshAsset()` でメッシュをディープコピーし `.asset` として保存
- 保存先フォルダは Inspector 上で設定可能（デフォルト: `Assets/dennokoworks/CableGenerator/BakedMesh/`）
- フォルダが存在しない場合は `AssetDatabase.CreateFolder()` で自動作成
- 上書き時は確認ダイアログを表示
- 保存成功時は、Cableと同階層・同一Transformでベイク済みメッシュ用オブジェクトを自動作成し、元のCableオブジェクトは `EditorOnly` + 非アクティブに切り替える

## 拡張性
- 新しい `CableProfile` を追加するだけで断面を増やせる
- 将来的に `ICableProfileProvider` インターフェースを導入してランタイムロード等に対応可能
