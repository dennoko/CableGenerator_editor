# 要件定義書

## 目的
Unity エディタ上で、始点と終点を指定しベジェ曲線を編集して背景用のメッシュ（道、壁、パイプ、ケーブル等）を直感的に作成できる拡張機能を提供する。

## 対象環境
- Unity 2022 以降
- エディタ拡張（Scene ビュー / Inspector）として動作

## ユーザー像
- レベルデザイナー、ワールドビルダー

## 基本要件（UX）
- 2クリックでの初期生成（始点・終点）
- Sceneビュー上でのハンドルによる制御点編集（ドラッグ）
- ハンドルはカメラ距離に依存しない固定見た目で操作しやすいこと
- 制御点の制約モード（Free／Aligned／Mirrored）を提供し色で判別
- 編集と同時にリアルタイムでメッシュプレビューが更新される
- Inspector で幅・厚み・分割数（滑らかさ）をスライダーで調整可能
- UV は曲線長に応じて自動スケーリング（タイリング）される
- Undo/Redo に対応し、変更は Unity の保存フローに反映される

## 機能要件（実装に必要な振る舞い）
- ベジェスプラインの制御点データ保持
- スプラインを一定間隔でサンプリングし局所座標系（位置・接線・法線・従法線）を計算
- 断面プロファイルをスプラインに沿って押し出すメッシュ生成
- メッシュは最小限の割り当てで更新（Mesh キャッシュ、MarkDynamic、List 再利用）
- ScriptableObject ベースの断面プロファイルをサポートし差し替え可能にする
- 標準の `Splines` パッケージを利用可能にする設計
- 生成メッシュを `.asset` ファイルとして保存（Bake）できる機能を提供する
- メッシュ保存先フォルダを Inspector 上で指定可能にする（デフォルト: `Assets/dennokoworks/CableGenerator/BakedMesh/`）
- Bake保存後、同階層にベイク済みメッシュを設定した `MeshFilter`/`MeshRenderer` オブジェクトを自動生成し、元のCableオブジェクトを `EditorOnly` タグ + 非アクティブ化できること
- スプラインのノットにオブジェクトをアタッチする機能を提供する（CableKnotAttachment）

## 非機能要件
- エディタで操作中の遅延は最小限（実用的には操作中のフレーム落ちを回避）
- メモリ割り当ては最小化し GC 発生を抑制する
- 生成メッシュは描画に適した法線・UV を持つ

## 今後の拡張ポイント
- 交差点自動生成や分岐処理
- 断面ごとの物理マテリアル、Collider 生成オプション

## 受け入れ基準
- 初期生成: オブジェクトを Scene 上で始点・終点をクリックするだけでスプラインと初期メッシュが生成されること
- 編集反映: 制御点をドラッグした際にメッシュがリアルタイムで更新され、操作感に目立つ遅延がないこと（目標: 操作時平均フレーム時間 < 33ms）
- UV 保持: 長尺のスプラインでテクスチャが著しく引き伸ばされないこと（タイリングで継ぎ目が目立たない）
- Undo/Redo: 制御点の追加・移動・削除が Undo/Redo で復元可能であること

## 用語定義
- Spline / SplineContainer: Unity の Splines パッケージで用いられる曲線データコンテナ
- CableProfile: 断面プロファイルを提供する `ScriptableObject`（頂点・法線・U を定義）
- Sampling: スプライン上を t(0..1) で分割して点列を得る処理
- RMF (Rotation Minimizing Frames): スプラインに沿った座標系を作る際のねじれを最小化する手法
