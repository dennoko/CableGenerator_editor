# CableGenerator — 使い方ガイド

## 1. ツール概要

CableGenerator は、ベジェスプラインに沿ってプロシージャルメッシュをリアルタイム生成する Unity エディタ拡張です。VRChat ワールド制作を主な用途として設計されており、ケーブル・パイプ・道路など、一定の断面形状を 3D パスに沿って押し出した形状を手軽に作れます。

**主な機能：**

- スプラインを編集するたびにメッシュをリアルタイム再生成
- `CableProfile` ScriptableObject による断面形状の自由なカスタマイズ（継承で拡張可能）
- Scene ビューでの制御点・接線インタラクティブ編集
- スプライン補助ツール：2点選択、ノット細分化、たわみシミュレーション、面投影
- ライトマップ UV（UV1）の自動パッキング
- ワンクリックでベイク済みメッシュを `.asset` としてエクスポート
- すべての操作が Unity の Undo/Redo に対応

**動作要件：**

- Unity 2022 以降
- Unity Splines パッケージ
- Unity.Mathematics パッケージ

## 2. 基本的な使い方

### 2.1 ケーブルオブジェクトの作成

Unity メニューバーから：

```
GameObject > Cable Generator > Create Cable
```

`Cable` という名前の GameObject が生成され、以下のコンポーネントが自動で追加されます。

| コンポーネント | 役割 |
|---|---|
| `SplineContainer` | ベジェスプライン（デフォルトで 2 制御点） |
| `MeshFilter` | 生成されたメッシュを保持 |
| `MeshRenderer` | メッシュの描画（デフォルトマテリアル適用済み） |
| `CableGenerator` | メッシュ生成エンジン |

### 2.2 断面プロファイルの割り当て

Cable オブジェクトを選択し、**CableGenerator** インスペクタの **断面プロファイル** フィールドに `CableProfile` アセットを設定します。

プロファイルアセットの作成：

```
Project ウィンドウ内で右クリック > Create > CableGenerator > Profiles > [プロファイルの種類]
```

プロファイルを設定するまでメッシュは生成されません。

### 2.3 スプラインの形状編集

Cable オブジェクトを選択して Scene ビューを開くと、以下のハンドルが表示されます。

- **色付きの球** — 各制御点（ノット）。色は接線モードを示します（§3.3 参照）。
- **青 / オレンジの球と線** — 接線ハンドル（In / Out）。
- **黄色の折れ線** — スプラインのプレビュー。
- **[N] / [N]▶ / ◀[N] ラベル** — 各ノットの上に表示されるインデックス番号。始点ノットは **[N]▶**、終点ノットは **◀[N]** で表示されます。

| 操作 | 方法 |
|---|---|
| 制御点を移動 | ノットの XYZ 矢印ハンドルをドラッグ |
| 接線を調整 | 青（In）またはオレンジ（Out）の球をドラッグ |
| ノットを選択 | Scene ビューの色付き球をクリック |
| 複数のノットを選択 | **Shift キーを押しながら**球をクリック |

### 2.4 制御点の追加と削除

**SplineContainer** インスペクタの **制御点リスト** セクションを使います。

- **＋ 制御点を追加** — 現在選択中のノットの後に新しいノットを追加します。途中のノットが選択中の場合は選択ノットと次のノットの中間地点に挿入されます。末尾ノットが選択中の場合は接線方向に 2 m オフセットして追加されます。
- 各行の **×** ボタン — そのノットを削除します（最低 2 ノット必要。2 ノットのときは無効化されます）。

### 2.5 メッシュ品質の調整

| パラメータ | 場所 | 効果 |
|---|---|---|
| 分割数（滑らかさ） | CableGenerator インスペクタ | スプライン方向のリングセグメント数（2〜256）。大きいほど曲線が滑らか。 |
| UVタイリング | CableGenerator インスペクタ | UV0 の V 軸タイリング倍率。テクスチャを繰り返す頻度を調整します。 |

### 2.6 ベイク済みメッシュのエクスポート

形状が確定したら VRChat アップロード用にエクスポートします。

1. CableGenerator インスペクタの **エクスポート** セクションを展開します。
2. （任意）**...** ボタンで `Assets/` 以下の保存先フォルダを選択します。空白の場合はデフォルトフォルダが使われます。
3. **メッシュを保存 (.asset)** をクリックします。

実行される処理：

- 現在のメッシュが `.asset` ファイルとして保存されます。
- 同じ位置・回転・スケールで `<名前>_cable_baked` という GameObject が新規作成され、保存済みメッシュとマテリアルが割り当てられます。
- 元の Cable オブジェクトは `EditorOnly` タグが付いて非アクティブになり、VRChat ビルドから自動的に除外されます。

## 3. UI 要素の詳しい解説

### 3.1 CableGenerator インスペクタ

#### 断面プロファイルの設定 *(常時表示)*

| UI 要素 | 内容 |
|---|---|
| 断面プロファイル | メッシュ断面を定義する `CableProfile` アセット。必須項目。 |
| 分割数（滑らかさ） | スプライン方向のリング数（2〜256）。 |
| UVタイリング | UV0 の V 軸タイリング倍率。 |
| メッシュを再生成 | メッシュを即時に強制再生成します。 |

---

#### 2点選択でスプライン配線 *(折りたたみ)*

| UI 要素 | 内容 |
|---|---|
| コライダーを付与 | シーン内の対象オブジェクトすべてに一時的な `MeshCollider` を追加し、レイキャスト（2点選択・面スナップ）の対象にします。バッチ処理で追加され、処理中はプログレスバーが表示されます。コライダーが既に付与済みの場合はボタンのラベルが **コライダーを再付与** に変わります。 |
| コライダーを削除 | 上のボタンで追加した一時コライダーをすべて削除します。 |
| ハンドルの長さ | レートスライダー。右にドラッグするとすべての接線ハンドルが比例して伸び、左にドラッグすると縮みます。離すと停止します。現在の長さが右側にメートルで表示されます。 |
| 2点選択でSplineを設定 | 2点選択モードに入ります。Scene ビューでコライダーのある面を 2 回クリックすると、その 2 点を始点・終点とし、面法線を向いたスプラインが作成されます。**対象メッシュにコライダーが必要（MeshCollider 推奨）。** |
| やり直し *(選択モード中)* | 1点目の選択をクリアして最初からやり直します。 |
| キャンセル *(選択モード中)* | 変更なしで選択モードを終了します。 |

> **注意：** Box・Capsule・Sphere コライダーは法線方向がずれる場合があります。正確な向きには MeshCollider を使用してください。

---

#### ノットの細分化・等分 *(折りたたみ)*

| UI 要素 | 内容 |
|---|---|
| 追加ノットモード | 新規挿入されるノットの接線モード（`AutoSmooth` / `Mirrored` / `Broken`）。 |
| 始点-終点 分割数 | 始点〜終点間に等間隔で作成するノット数（区間数）。 |
| 始点-終点を等分してノット再配置 | 内部ノットをすべて削除し、始点〜終点の直線上に等間隔で新しいノットを配置します。始点と終点は保持されます。 |
| 全区間を細分化してノット追加 | 既存の各セグメントの曲線中点に新しいノットを 1 つずつ挿入します。既存ノットは保持されます。 |

---

#### ノットを面にスナップ配置 *(折りたたみ)*

レイキャストによってノットをシーン内のジオメトリ面にスナップします。

| UI 要素 | 内容 |
|---|---|
| 対象ノット Index | 投影するノットのインデックス（単一選択時）。 |
| 複数選択 | Scene ビューで **Shift+クリック** してノット球を選択すると、その全インデックスが投影対象になります。インスペクタにインデックス一覧が表示されます。 |
| 投影方向 | レイキャストの方向ベクトル（ワールド空間）。 |
| 方向をローカル扱い | ON にすると、投影方向がオブジェクトのローカル空間として解釈されます。 |
| 最大距離 | レイキャストの最大距離（メートル）。 |
| 面オフセット | ヒット法線方向にノットを少し浮かせるオフセット量。Zファイティング防止に使います。 |
| LayerMask | レイキャスト対象レイヤーのマスク。 |
| 指定ノットを面へ投影 | 選択ノットからレイを発射し、ヒット位置に移動します。結果はボタン下に表示されます。Shift+クリックで複数ノットを選択中のときはボタンのラベルが **選択した N ノットを面へ投影** に変わります。 |

---

#### ケーブルたわみ設定 *(折りたたみ)*

中間ノットを挿入して重力によるたわみをシミュレートします。

| UI 要素 | 内容 |
|---|---|
| たわみノットを挿入 | 各セグメントの中点にたわみノットを 1 つずつ挿入します。ノット数はおよそ 2 倍になります。 |
| 降下距離 | たわみノットが下方向に下がる距離（0〜5 m）。挿入後にリアルタイムで調整できます。 |
| Mirrored ハンドル | ON のときたわみノットの接線モードが `Mirrored`（対称）、OFF のとき `AutoSmooth` になります。 |
| ハンドルの長さ | たわみノットのハンドル長さ。**Mirrored ハンドル** が ON のときのみ有効です。 |

> **注意：** スプラインの構造が変わった場合（Undo・ノットの追加削除など）、たわみ調整モードは自動的に終了します。再度 **たわみノットを挿入** を実行してください。

#### アタッチメント *(折りたたみ)*

SplineContainer にスプラインが存在する場合のみ表示されます。

| UI 要素 | 内容 |
|---|---|
| ノット N にアタッチメントを追加 | `Attachment_KnotN` という子 GameObject を作成し、`CableKnotAttachment` コンポーネントを追加します。この子オブジェクトはノット N のワールド位置に追従します。 |

作成された子オブジェクトの **CableKnotAttachment** コンポーネントで以下の設定ができます：

| フィールド | 内容 |
|---|---|
| knotIndex | 追従するノットのインデックス番号。 |
| prefab | 配置する **Prefab または FBX モデルアセット**。`.prefab` ファイルと Prefab 化されていない `.fbx` ファイルの両方を受け付けます。Project ウィンドウからドラッグ＆ドロップで設定します。 |
| positionOffset | ノット位置からのオフセット（ローカル空間）。 |
| rotationOffset | 追加回転（オイラー角）。 |
| scale | 配置インスタンスのスケール。X・Y・Z 軸を個別に設定できるため、特定の軸だけ拡大・縮小して引き伸ばしたり潰したりすることも可能です。 |

> **補足：** `.prefab` ファイルは Prefab 接続を維持した状態でインスタンス化されます。`.fbx` などのモデルアセットは接続なしで直接インスタンス化されます。

### 3.2 SplineContainer インスペクタ

`SplineContainer` が `CableGenerator` と同じ GameObject にある場合、カスタム UI に置き換えられます。最上部の **カスタムUIを使用** トグルを OFF にすると Unity 標準の Splines UI に切り替わります。

#### ステータスバー

| UI 要素 | 内容 |
|---|---|
| 制御点: N | 現在のノット数。 |
| 全長: X.XX m | スプラインの弧長（ワールド空間）。 |
| ループ | スプラインを閉じたループにする / 開く。 |
| ↕ 反転 | スプラインの向きを反転します（始点と終点を入れ替え、接線も反転）。 |
| ⟺ 均等配置 | 全ノットを現在の弧長に沿って等間隔に再配置します。始点と終点の位置は保持されます。 |

---

#### 制御点リスト

ノットを 1 行ずつ一覧表示します。

| コントロール | 内容 |
|---|---|
| [N] / [N] スタート / [N] エンド | クリックしてそのノットを選択します。Scene ビューで強調表示されます。 |
| 接線モードドロップダウン | **自動** = AutoSmooth、**スムーズ** = Mirrored、**コーナー** = Broken |
| × | そのノットを削除します（2 ノット以下のときは無効）。 |
| ＋ 制御点を追加 | 選択中のノットの次に新しいノットを追加します。 |

**Scene ビューでのノット球の色（接線モード別）：**

| 色 | モード |
|---|---|
| シアン | AutoSmooth（自動） |
| 緑 | Mirrored（スムーズ） |
| 黄 | Continuous |
| 赤 | Broken（コーナー） |

#### ノット詳細パネル

現在選択中のノットの詳細編集エリアです。

| UI 要素 | 内容 |
|---|---|
| Global / Local トグル | 回転・接線角度の表示空間を切り替えます。**位置フィールドは常にワールド座標で表示されます**（このトグルの影響を受けません）。 |
| ◀ / ▶ ボタン | 前後のノットに移動します。 |
| 位置 | ノットの**ワールド座標**。Global / Local トグルの影響を受けず、常にワールド座標で表示・編集できます。 |
| 回転・接線（詳細） | 常時表示のセクション。**自動**（AutoSmooth）モードのときはヘルプメッセージが表示され各コントロールは無効になります。**スムーズ** または **コーナー** モードのときのみコントロールが有効になります。 |

**回転・接線（詳細）内の UI：**

| UI 要素 | 内容 |
|---|---|
| 回転 X / Y / Z | ノットのオイラー角。**0** でその軸をリセット、**−** / **+** で 15° ずつ変更します。 |
| ハンドル長さ（同期） | *(スムーズ / Continuous のみ)* TangentIn と TangentOut の長さをまとめて変更するレートスライダー。 |
| タンジェントOut 角度 | *(コーナーのみ)* 出力接線の方向。 |
| タンジェントOut 長さ | *(コーナーのみ)* 出力接線の長さ（レートスライダー）。 |
| タンジェントIn 角度 | *(コーナーのみ)* 入力接線の方向（Out と独立）。 |
| タンジェントIn 長さ | *(コーナーのみ)* 入力接線の長さ（レートスライダー）。 |

## 4. QA

**Q: Cable オブジェクトを作成したのにメッシュが表示されません。**  
A: **断面プロファイル** フィールドに `CableProfile` アセットを設定してください。プロファイルが未設定の場合、メッシュは生成されません。

**Q: 2点選択でクリックしても反応しません。**  
A: クリック対象のメッシュにコライダーが必要です。対象オブジェクトのインスペクタで `MeshCollider` を追加してください。Box・Capsule・Sphere コライダーでも動作しますが、ケーブルの向きがずれる場合があります。

**Q: たわみのスライダーが操作できなくなりました。**  
A: Undo・ノットの追加削除など、スプラインの構造が変わるとたわみ調整モードが自動終了します。**たわみノットを挿入** を再度実行すると調整モードに戻ります。

**Q: オリジナルの断面形状を使いたいです。**  
A: `CableGeneratorRuntime` ネームスペースで `CableProfile` を継承したクラスを作成し、`GetVertices()`・`GetNormals()`・`GetUCoords()` を実装してください。`[CreateAssetMenu]` 属性を付けると Project ウィンドウから作成できます。`CableGenerator` やインスペクタのコードを変更する必要はありません。

**Q: スプラインをループ（輪）にしたいです。**  
A: **SplineContainer** インスペクタのステータスバーにある **ループ** トグルを ON にしてください。スプラインが閉じられ、最後のセグメントが最初の制御点に繋がります。

**Q: 急カーブ付近でメッシュがねじれています。**  
A: スプラインの接線方向が急変するとパラレルトランスポートフレームが反転することがあります。ねじれ付近に中間ノットを追加し、**ノット詳細** の回転フィールドでノットの向きを手動で補正してください。

**Q: Undo/Redo は使えますか？**  
A: はい。制御点の移動・追加・削除・投影・たわみ挿入・エクスポートなど、すべての操作が Unity の Undo システムに登録されています。**Ctrl+Z** (Windows) / **Cmd+Z** (Mac) で取り消せます。

**Q: エクスポート後に元のケーブルとベイク済みオブジェクトが両方表示されます。**  
A: エクスポート後、元の Cable オブジェクトには `EditorOnly` タグが設定され、非アクティブになります。VRChat ビルドには含まれません。エディタ上で気になる場合は Hierarchy でオブジェクトが非アクティブ（グレー表示）になっていることを確認してください。

**Q: アタッチメントの prefab フィールドに FBX を設定できますか？**  
A: できます。`.prefab` ファイルに加え、Prefab 化されていない `.fbx` モデルアセットも対応しています。Project ウィンドウから FBX をドラッグして prefab フィールドにドロップするだけで設定できます。`.prefab` は Prefab 接続を維持してインスタンス化され、`.fbx` は接続なしで直接インスタンス化されます。

**Q: スクリプトからスプラインを動的に変更してメッシュを更新できますか？**  
A: できます。`CableGenerator` は `Spline.Changed` イベントを購読しているため、スクリプトから `SplineContainer` を変更すると自動的にメッシュが再構築されます。コンポーネントは `[ExecuteAlways]` なのでエディタ実行中・再生中ともに動作します。

**Q: ライトマップ UV（UV1）が引き延ばされて見えます。**  
A: UV1 はプロファイルの周長とスプライン長から棚パッキング（Shelf Packing）アルゴリズムで自動生成されます。アスペクト比が極端なケーブルではパッキングが最適でない場合があります。その場合はメッシュアセットを外部 DCC ツールでインポートし、UV1 を手動で展開・調整してください。
