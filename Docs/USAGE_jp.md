## はじめに

Cable Generator は、Unity の Splines パッケージを利用して、ケーブル・パイプ・道・壁などの押し出しメッシュを直感的に作成するエディタ拡張です。

**前提条件**: Unity 2022 以降、`com.unity.splines` パッケージがインストール済みであること。

---

## ケーブルオブジェクトの作成

### 手順

1. Unity メニューバーから **GameObject > Cable Generator > Create Cable** を選択
2. Scene 上に「Cable」という名前の GameObject が生成されます

生成されたオブジェクトには以下のコンポーネントが自動で付きます:

| コンポーネント | 役割 |
|---|---|
| Spline Container | カーブのデータ（始点・終点の2ノット付き） |
| Mesh Filter | 生成されたメッシュの保持 |
| Mesh Renderer | メッシュの描画 |
| Cable Generator | メッシュ生成の制御（本拡張の本体） |

> この時点ではまだメッシュは表示されません。次のステップで **断面プロファイル** をセットする必要があります。

---

## 断面プロファイルの作成とセット

断面プロファイルとは、ケーブルの「輪切りにしたときの形」を定義するアセットです。これをスプラインに沿って押し出すことでメッシュが生成されます。

### ステップ 1: プロファイルアセットを作成する

Project ウィンドウで右クリック → **Create** から以下のいずれかを選択します:

| メニュー | 断面の形状 | 用途の例 |
|---|---|---|
| **Cable Generator > Heavy Duty Cable Profile** | 丸型（太い円）。リブ（凹凸）オプション付き | 電源ケーブル、ホース、パイプ |
| **Cable Generator > Flat Cable Profile** | 角丸の長方形（平たい形） | フラットケーブル、リボンケーブル、ベルト |
| **Cable Generator > Parallel Wire Profile** | 2つの円が並んだメガネ型 | 電線2本組、スピーカーケーブル |

選択すると Project ウィンドウにアセットファイルが作成されます。名前は自由に変更してください。

### ステップ 2: プロファイルのパラメータを調整する

作成したプロファイルアセットを Project ウィンドウで選択すると、Inspector にパラメータが表示されます。

**Heavy Duty Cable Profile の場合:**

| パラメータ | 説明 | 目安 |
|---|---|---|
| Radius | ケーブルの半径 | 0.01〜0.1 程度 |
| Segments | 円周の分割数。大きいほど滑らか | 8〜32 |
| Rib Count | 凹凸リブの数。0 で滑らかな円 | 0〜12 |
| Rib Depth | リブの深さ（半径に対する割合） | 0〜0.3 |

**Flat Cable Profile の場合:**

| パラメータ | 説明 | 目安 |
|---|---|---|
| Width | 幅（X方向の全長） | 0.05〜0.2 |
| Thickness | 厚み（Y方向の全長） | 0.01〜0.05 |
| Corner Radius | 角丸の半径 | 0.003〜0.01 |
| Corner Segments | 角丸の分割数 | 2〜4 |

**Parallel Wire Profile の場合:**

| パラメータ | 説明 | 目安 |
|---|---|---|
| Wire Radius | 各ワイヤーの半径 | 0.01〜0.03 |
| Spacing | 2本のワイヤー中心間の距離 | 0.04〜0.08 |
| Segments | 各円の分割数 | 6〜16 |

### ステップ 3: Cable Generator にプロファイルをセットする

1. Scene または Hierarchy で **Cable オブジェクト** を選択
2. Inspector の Cable Generator コンポーネントにある **「断面プロファイル」** 欄を確認
3. 以下のいずれかの方法でプロファイルをセット:
   - **ドラッグ＆ドロップ**: Project ウィンドウからプロファイルアセットを「断面プロファイル」欄にドラッグ
   - **ピッカー**: 「断面プロファイル」欄の右端にある ◎ ボタンをクリックし、一覧から選択

**セットした瞬間にメッシュが生成・表示されます。**

## Inspector パラメータの調整

Cable オブジェクトを選択した状態で、Inspector の Cable Generator コンポーネントに表示されるパラメータ:

| パラメータ | 説明 | デフォルト |
|---|---|---|
| **断面プロファイル** | 使用する断面プロファイルアセット | なし（必須） |
| **分割数（滑らかさ）** | スプライン方向のメッシュ分割数。大きいほどカーブが滑らか | 32 |
| **UVタイリング** | テクスチャの繰り返し密度。長いケーブルで引き伸ばされる場合に値を大きくする | 1.0 |

- **分割数** はスライダーで 2〜256 の範囲で調整可能です。通常は 16〜64 で十分です。
- **UVタイリング** は値を大きくするとテクスチャが細かく繰り返され、小さくすると引き伸ばされます。
- パラメータを変更するとリアルタイムでメッシュが更新されます。

## Scene ビューでのカーブ操作

### 制御点（ノット）の移動

Cable オブジェクトを選択した状態で Scene ビューを見ると、スプライン上に **色付きの球体マーカー** と **移動ハンドル（XYZ 矢印）** が表示されます。

- ハンドルの矢印をドラッグすると制御点が移動し、メッシュがリアルタイムで追従します
- ハンドルはカメラからの距離に関係なく一定のサイズで表示されます

### 制御点の色と制約モード

制御点の球体の色は、そのノットのタンジェント制約モードを表しています:

| 色 | モード | 意味 |
|---|---|---|
| 🟢 **緑** | Mirrored | 入力と出力のタンジェントが完全に対称。滑らかな曲線に最適 |
| 🟡 **黄** | Continuous (Aligned) | タンジェントの方向は一致するが長さは独立。滑らかさを保ちつつ非対称なカーブが作れる |
| 🔴 **赤** | Broken (Free) | 入力と出力のタンジェントが完全に独立。鋭角な折れ曲がりが作れる |
| 🔵 **シアン** | Auto Smooth | Unity が自動で滑らかなタンジェントを計算 |

> 制約モードの変更は、Spline Container コンポーネント側または Unity の Spline ツールで行えます。

### タンジェントハンドルの操作

各制御点から 2 本のタンジェントハンドル（小さな球体）が伸びています:

- **青色の線＋球**: 入力タンジェント（カーブの入り方を制御）
- **オレンジ色の線＋球**: 出力タンジェント（カーブの出方を制御）

タンジェントの球をドラッグすると、カーブの曲がり具合が変わります。球を制御点から遠ざけるほどカーブが緩やかになり、近づけるほど急になります。

### 制御点の追加・削除

制御点の追加・削除は Unity 標準の Spline ツールで行います:

1. Cable オブジェクトを選択
2. Inspector の **Spline Container** コンポーネントを展開
3. 「Edit Spline」ボタンをクリックして Spline 編集モードに入る
4. スプライン上をクリックしてノットを追加、または既存ノットを選択して Delete キーで削除

### スプラインのプレビュー線

Cable オブジェクト選択中は、Scene ビューに **黄色い半透明のプレビュー線** がスプラインの経路に沿って表示されます。これによりメッシュの中心線を視覚的に確認できます。

## マテリアルの適用

1. Cable オブジェクトの **Mesh Renderer** コンポーネントで Materials を設定
2. マテリアルのテクスチャは UV に基づいて貼られます:
   - **U 方向**: 断面の周方向（ケーブルを輪切りにした方向）
   - **V 方向**: スプラインに沿った方向（ケーブルの長手方向）
3. テクスチャが引き伸ばされる場合は **UVタイリング** の値を大きくしてください

## Undo/Redo

以下の操作はすべて Unity の Undo/Redo（Ctrl+Z / Ctrl+Y）に対応しています:

- 制御点の移動
- タンジェントの操作
- Inspector パラメータの変更
- ケーブルオブジェクトの作成

## Tips とトラブルシューティング

### メッシュが表示されない

- **断面プロファイルがセットされていない**: Inspector の「断面プロファイル」に必ずアセットをセットしてください
- **スプラインのノットが1つしかない**: 最低2つの制御点が必要です
- **Mesh Renderer にマテリアルが割り当てられていない**: Materials を確認してください

### メッシュがカクカクしている

- Inspector の **分割数（滑らかさ）** を大きくしてください（32〜64 推奨）
- 断面プロファイルの **Segments** も大きくすると断面が滑らかになります

### テクスチャが引き伸ばされる

- **UVタイリング** を大きい値（2〜10 等）にしてください
- ケーブルが長いほど大きい値が必要です

### パフォーマンスが悪い

- 分割数を小さくしてください（16〜32 で十分な場合が多い）
- 断面プロファイルの Segments も控えめにしてください

### プロファイルを変更したのに反映されない

- Inspector の **「メッシュを再生成」** ボタンを押してください
- プロファイルアセットのパラメータ変更後、Cable オブジェクトを再選択すると反映されます
